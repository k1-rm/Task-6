# Task-6
In this task, I implemented the K-Nearest Neighbors (KNN) classification algorithm using the Iris dataset. I began by normalizing the feature values using StandardScaler, as KNN relies on distance calculations. I then split the dataset into training and testing sets and trained KNN models with different values of K (1, 3, 5, 7, 9) to observe how accuracy varied. I evaluated each model using accuracy score, confusion matrix, and classification report. Additionally, I visualized the accuracy trend across K values and plotted 2D decision boundaries using the first two features for better interpretability. This task helped me understand how instance-based learning works and how K influences classification performance.
